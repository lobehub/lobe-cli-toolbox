## API

`createTaskList(options?: TaskListOptions): TaskList`

| Method                               | Description                          |
| ------------------------------------ | ------------------------------------ |
| `start(id, { tag?, title })`         | Add a running task                   |
| `update(id, { detail?, progress? })` | Patch detail / 0–100 progress        |
| `finish(id, status, detail?)`        | `done` \| `error` \| `warning`       |
| `stop()`                             | Unmount and flush; returns a Promise |
