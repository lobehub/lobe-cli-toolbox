## API

| Call                      | Behavior                                  |
| ------------------------- | ----------------------------------------- |
| `alert.success(text)`     | Log success                               |
| `alert.info(text)`        | Log info                                  |
| `alert.warn(text)`        | Log warning                               |
| `alert.error(text)`       | Log error                                 |
| `alert.error(text, true)` | Log error and `process.exit(1)` (`never`) |
| `setAlertSink(sink)`      | Divert logs into a live view              |
